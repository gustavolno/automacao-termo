# Ponytail Skill: Lean & Token-Efficient Coding
- Follow YAGNI (You Aren't Gonna Need It). Never over-engineer.
- Reuse existing functions, modules, and utilities in the project before creating new ones.
- Minimize diffs: only touch the exact lines required for the task.
- Favor standard library and native language features over adding external dependencies.
- Omit conversational fluff, verbose inline explanations, and redundant comments.
